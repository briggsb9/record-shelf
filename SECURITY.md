# Security policy

## Supported versions

Security fixes are applied to the latest release and the `main` branch. Older test releases are not maintained separately.

## Reporting a vulnerability

Please do not disclose a suspected vulnerability in a public issue. Use **Security → Report a vulnerability** on the GitHub repository to send the maintainers a private report. If that option is unavailable, open an issue containing no sensitive details and ask the maintainer to arrange a private reporting channel.

Include the affected version and platform, reproduction steps, potential impact and any suggested mitigation. Please also remove personal music metadata, NAS addresses, access tokens and credentials from logs or screenshots.
